# 🎰 Bingo Web Interativo

Um jogo de bingo completo com **cartela virtual** e **sistema de sorteio**, desenvolvido em HTML, CSS e JavaScript.

![Preview]([https://via.placeholder.com/800x400/007ced/ffffff?text=Bingo+Web+Interativo](https://github.com/souzaseven/Bingo/blob/jogos/painel-bingo.png?raw=true).

## ✨ Funcionalidades

- **Cartela Dinâmica**
  - Geração aleatória de números por coluna (B-I-N-G-O)
  - Marcação automática com efeito visual
  - Botão "Reset" para limpar marcações
  - Nova cartela com um clique

- **Sistema de Sorteio**
  - Sorteador de bolinhas com exclusão de repetidos
  - Painel visual com a última bola sorteada
  - Histórico de bolinhas sorteadas
  - Reset completo do sorteio

## 🛠 Tecnologias

- **Frontend**
  - HTML5 semântico
  - CSS3 com Flexbox
  - JavaScript (ES6)
  - jQuery (para manipulação do DOM)
