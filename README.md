# 🎰 Bingo Web Interativo

Um jogo de bingo completo com **cartela virtual** e **sistema de sorteio**, desenvolvido em HTML, CSS e JavaScript.

![Preview](https://github.com/souzaseven/Bingo/blob/jogos/painel-bingo.png?raw=true)

## ✨ Funcionalidades

- **Cartela Dinâmica**
  - Geração aleatória de números por coluna (B-I-N-G-O)
  - Marcação automática com efeito visual ("X" vermelho)
  - Botão "Reset" para limpar marcações
  - Nova cartela com um clique (recarrega a página)

- **Sistema de Sorteio**
  - Sorteador de bolinhas sem repetição (1-75)
  - Painel visual com a última bola sorteada (formato B1, I16, N32, etc)
  - Destaque automático na cartela quando sorteado
  - Reset completo do sorteio (limpa histórico)

## 🛠 Tecnologias

- **Frontend**
  - HTML5 semântico
  - CSS3 com Flexbox e responsividade
  - JavaScript (ES6)
  - jQuery 3.7.0 (para manipulação do DOM)
